# Эмулятор оболочки, этап 2

## 1. Общее описание

* Это учебная программа, которая похожа на командную строку.
* У программы есть окно, написанное на tkinter.
* Название окна показывает имя пользователя и компьютера.
* На этом этапе добавлены параметры запуска.
* Ещё можно запустить скрипт: программа сама выполнит команды из файла.
* Команды ls и cd пока только печатают своё имя и аргументы.
* Команда exit закрывает окно.

## 2. Описание функций и настроек

* main.py читает параметры, показывает их в консоли и запускает окно.
* src/config.py хранит функцию razobrat_parametry. Она читает параметры запуска.
* src/script_runner.py хранит функцию prochitat_skript. Она читает файл со скриптом.
* В скрипте пустые строки и строки с решёткой в начале пропускаются.
* src/gui.py и src/parser.py работают так же, как на этапе 1.

Параметры запуска:

* --vfs-path путь к файлу виртуальной файловой системы.
* --script путь к файлу со скриптом. Пример: scripts/demo.txt.
* Оба параметра необязательные.
