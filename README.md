# Эмулятор оболочки, этап 1

## 1. Общее описание

* Это учебная программа, которая похожа на командную строку.
* У программы есть окно, написанное на tkinter.
* В окне есть поле вывода и строка для ввода команд.
* Название окна показывает имя пользователя и компьютера.
* Команды ls и cd пока только печатают своё имя и аргументы.
* Команда exit закрывает окно.
* Если команды нет в списке, программа пишет сообщение об ошибке.

## 2. Описание функций и настроек

* main.py создаёт окно и запускает программу.
* src/gui.py хранит класс Prilojenie. Он рисует окно и обрабатывает команды.
* src/parser.py хранит функцию razobrat_komandu. Она делит строку на слова.
* Слова в двойных кавычках считаются одним словом.
* Настроек запуска на этом этапе нет.

## 3. Сборка и тесты

* Сборка не нужна. Нужен только Python 3 с tkinter.
* Запуск из папки проекта: python main.py
* Запуск на Windows: run.bat
* Папка tests пока пустая, автоматических тестов нет. Проверка делается вручную в окне программы.

## 4. Примеры использования

Ввод в окне программы:

```
ls -la
cd "My Documents"
abc
exit
```

Что выведет программа:

```
> ls -la
ls stub: args=['-la']
> cd "My Documents"
cd stub: args=['My Documents']
> abc
Error: unknown command 'abc'
```

После команды exit окно закрывается.
