# Эмулятор командной строки (Вариант 7)

Практическая работа №1 по конфигурационному управлению, ИКБО-50-25.
Этап 3.

## 1. Общее описание

Эмулятор оболочки ОС с окном на tkinter. Добавилась виртуальная
файловая система. Реальная папка с диска целиком загружается в
память, и все дальнейшие действия происходят там, не трогая
настоящие файлы.

## 2. Описание функций и настроек

- В заголовке окна выводится имя пользователя и имя компьютера.
- Парсер понимает команды с аргументами в кавычках.
- Параметр vfs-path теперь реально загружает указанную папку в
  память.
- Параметр script задаёт путь к файлу со списком команд, как раньше.
- Новая команда vfs-save сохраняет то, что сейчас в памяти, обратно
  на диск по указанному пути.
- Команды ls и cd пока всё ещё заглушки, реально ходить по
  загруженной папке они не умеют, это будет добавлено позже.
- Команда exit закрывает окно.

## 3. Примеры использования

Запуск с загрузкой папки: python main.py --vfs-path vfs_samples/minimal

Внутри программы: команда vfs-save с новым путём сохраняет копию
загруженной папки на диск по этому пути. Исходная папка при этом
не меняется, всё редактирование идёт только в памяти.
