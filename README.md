# Эмулятор оболочки, этап 2

## 1. Общее описание

* Это учебная программа, которая похожа на командную строку.
* На этом этапе эмулятор можно настраивать параметрами запуска.
* При запуске параметры печатаются в консоль.
* Можно запустить скрипт: программа сама выполнит команды из файла и покажет их в окне.
* Команды ls, cd и exit работают так же, как на этапе 1.

## 2. Описание функций и настроек

* main.py читает параметры, печатает их и запускает окно.
* src/config.py хранит функцию razobrat_parametry. Она читает параметры запуска.
* src/script_runner.py хранит функцию prochitat_skript. Она читает файл со скриптом.
* В скрипте пустые строки и строки, которые начинаются с решётки, пропускаются.
* src/gui.py и src/parser.py работают так же, как на этапе 1.

Параметры запуска:

* --vfs-path путь к папке виртуальной файловой системы.
* --script путь к стартовому скрипту. Пример: scripts/demo.txt.
* Оба параметра необязательные.

## 3. Сборка и тесты

* Сборка не нужна. Нужен только Python 3 с tkinter.
* Запуск без параметров: python main.py
* Запуск с параметрами: python main.py --vfs-path vfs --script scripts/demo.txt
* Запуск на Windows: run.bat --script scripts/demo.txt
* Папка tests пока пустая, автоматических тестов нет. Проверка делается запуском scripts/demo.txt.

## 4. Примеры использования

Запуск:

```
python main.py --vfs-path vfs --script scripts/demo.txt
```

Вывод в консоль при запуске:

```
Parametry zapuska:
  vfs-path = vfs
  script = scripts/demo.txt
```

Скрипт scripts/demo.txt:

```
# демонстрационный скрипт
ls -la
cd "My Documents"
abc
exit
```

В окне будут видны вводимые команды и ответы программы. Последняя команда exit закрывает окно.
