# Эмулятор командной строки (Вариант 7)

Практическая работа №1 по конфигурационному управлению, ИКБО-50-25.
Этап 2.

## 1. Общее описание

К эмулятору из этапа 1 добавлены параметры запуска и стартовый
скрипт. Теперь программу можно настроить при запуске и выполнить
заранее подготовленный список команд.

## 2. Описание функций и настроек

Функции этапа 1 сохранены: заголовок окна с именем пользователя и
компьютера, разбор команд с кавычками, заглушки ls и cd, команда
exit, сообщение об ошибке для неизвестных команд.

Новое на этапе 2:

- Параметр vfs-path: путь к папке для виртуальной файловой системы.
  Пока значение только запоминается и выводится в консоль.
- Параметр script: путь к файлу со стартовыми командами. Команды из
  файла выполняются автоматически, одна за другой.
- Формат скрипта: одна команда на строку. Пустые строки и строки,
  которые начинаются с решётки, пропускаются.
- При запуске в консоль выводятся значения заданных параметров.
