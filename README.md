# Эмулятор командной строки (Вариант 7)

Практическая работа №1 по конфигурационному управлению, ИКБО-50-25.
Этап 1.

## 1. Общее описание

Прототип эмулятора оболочки ОС с графическим интерфейсом на tkinter.
В окне можно вводить команды, но пока они только показывают, что
были получены.

## 2. Описание функций и настроек

- В заголовке окна выводится имя пользователя и имя компьютера.
- Парсер команд понимает аргументы в кавычках.
- Команды ls и cd пока заглушки, они выводят свои аргументы.
- Команда exit закрывает окно.
- Неизвестная команда выводит ошибку, программа продолжает работать.

Настроек и параметров запуска на этом этапе нет.
