# Эмулятор оболочки

## 1. Общее описание

Это учебная программа, которая похожа на командную строку. У неё есть окно на tkinter. Проект сделан в два этапа.

Этап 1:

* Окно с полем вывода и строкой ввода команд.
* В названии окна видны имя пользователя и компьютера.
* Команды ls и cd пока только печатают своё имя и аргументы.
* Команда exit закрывает окно.
* Если команды нет в списке, программа пишет сообщение об ошибке.

Этап 2:

* Параметры запуска.
* Запуск скрипта: программа сама выполняет команды из файла.
* При запуске параметры печатаются в консоль.

## 2. Описание функций и настроек

Этап 1:

* main.py создаёт окно и запускает программу.
* src/gui.py хранит класс Prilojenie. Он рисует окно и обрабатывает команды.
* src/parser.py хранит функцию razobrat_komandu. Она делит строку на слова. Слова в двойных кавычках считаются одним словом.

Этап 2:

* src/config.py хранит функцию razobrat_parametry. Она читает параметры запуска.
* src/script_runner.py хранит функцию prochitat_skript. Она читает файл со скриптом. Пустые строки и строки с решёткой в начале пропускаются.

Параметры запуска:

* --vfs-path путь к папке виртуальной файловой системы.
* --script путь к стартовому скрипту. Пример: scripts/demo.txt.
* Оба параметра необязательные.

## 3. Сборка и тесты

* Сборка не нужна. Нужен только Python 3 с tkinter.
* Запуск без параметров: python main.py
* Запуск с параметрами: python main.py --vfs-path vfs --script scripts/demo.txt
* Запуск на Windows: run.bat --script scripts/demo.txt
* Папка tests пока пустая, автоматических тестов нет. Проверка делается вручную в окне или запуском scripts/demo.txt.

## 4. Примеры использования

Запуск:

```
python main.py --vfs-path vfs --script scripts/demo.txt
```

Вывод в консоль при запуске:

```
Parametry zapuska:
  vfs-path = vfs
  script = scripts/demo.txt
```

Команды в окне:

```
> ls -la
ls stub: args=['-la']
> cd "My Documents"
cd stub: args=['My Documents']
> abc
Error: unknown command 'abc'
```

Команда exit закрывает окно.
